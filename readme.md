# Intelligent Clicking Engine (ICE)

ICE is a Minecraft autoclicking tool to bypass all serverside anticheats

## Context

The original code for ICE was developed in 2021 by Reakisyon and I using Lizzard clicker as a base. The auth and anti-debug are super awful, but functionality wise the clicker was - and still is - virtually undetectable by all serverside anticheats due to the simple click recording and playback functions.

This is the non-modified source code. Many attempts have been made to replicate this project, but this remains the first iteration.
