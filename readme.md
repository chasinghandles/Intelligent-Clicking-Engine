# Intelligent Clicking Engine (ICE)

ICE is a Minecraft autoclicking tool to bypass all serverside anticheats

## Context

The original code for ICE was developed in 2021 by Reakisyon and I using Lizzard clicker as a base. The auth and anti-debug were terrible, but functionality wise, the clicker was virtually undetectably by all serverside anticheats due to the click recording and playback functions.

This is the non-modified source code.
